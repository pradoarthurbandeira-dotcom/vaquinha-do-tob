# 🐄 Vaquinha - Site de Financiamento Coletivo

Um site moderno e responsivo para plataforma de financiamento coletivo (crowdfunding).

## 📋 Características

- ✨ Design moderno e responsivo
- 🎯 Seção de campanhas em destaque
- 📱 Mobile-first approach
- ⚡ Performance otimizada
- 🎨 Gradientes e animações suaves
- 📧 Formulário de contato

## 🚀 Começando

### Requisitos
- Um navegador moderno (Chrome, Firefox, Safari, Edge)
- (Opcional) Um servidor web local para testes

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/vaquinha-site.git
cd vaquinha-site
```

2. Abra o arquivo `index.html` no seu navegador:
```bash
open index.html
```

Ou use um servidor local:
```bash
python -m http.server 8000
# Acesse http://localhost:8000
```

## 📁 Estrutura do Projeto

```
vaquinha-site/
├── index.html      # Arquivo principal HTML
├── styles.css      # Estilos CSS
├── script.js       # JavaScript para interatividade
└── README.md       # Este arquivo
```

## 🎨 Seções

1. **Header/Navbar** - Navegação principal com links
2. **Hero Section** - Banner chamativo com CTA
3. **Campanhas** - Grid de campanhas em destaque com progresso
4. **Como Funciona** - 4 passos explicativos
5. **Contato** - Formulário de contato
6. **Footer** - Rodapé com links sociais

## 💻 Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, Gradients)
- JavaScript (Vanilla)

## 🔧 Personalizações

Você pode facilmente personalizar:

- **Cores**: Altere os valores HEX nos estilos CSS
- **Conteúdo**: Edite textos e imagens no HTML
- **Campanhas**: Adicione/remova cards de campanha
- **Formulário**: Configure o destino das mensagens

## 📱 Responsividade

O site é totalmente responsivo para:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)
